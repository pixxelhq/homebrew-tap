# Pixxel Homebrew Tap

Homebrew formulae for Pixxel open-source tools.

## Installation

```sh
brew tap pixxelhq/tap
brew install clay --formula
```

Or

```sh
brew install pixxelhq/tap/clay
```

## Available Formulae

| Formula | Description |
|---------|-------------|
| `clay`  | CLI for packaging ML models as deployable blocks |
